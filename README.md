# Manifest-V2-Archive

A community project to create an MV2 extension archive as a way to honor extension developers and ensure that MV2 remains easily accessible and usable.

# Background of the Manifest V2 Archive Project
1. To make it easier for many people to find MV2 extensions, which are currently difficult to locate manually in extension stores
2. To consolidate more MV2 extensions—which are scattered across various extension stores—into a single free and open-source repository accessible to everyone
3. To establish a daily automated archiving system to ensure the continued existence of MV2 as part of an effort to preserve extensions at risk of being removed from extension stores.
4. To uphold the hopes of many people that MV2 extensions, which have been in use for so long, will continue to be maintained, properly archived, and not become obsolete over time


# Main Section of the Archives
1. Wiki (https://github.com/VINTSPECT/Manifest-V2-Archive/wiki) consisting of:
   
   a. Guide to Installing Manifest V2 in Chromium‐Based Browsers (Developer Offline Mode)
   
   b. Guide to Installing Chrome Extensions on Firefox‐Based Browsers
   
   c. Tips for installing Firefox extensions in Chromium‐based browsers
   
   d. Manifest V2 Database
   
3. Offline Archive (https://github.com/VINTSPECT/Manifest-V2-Archive/releases/tag/1.0), an archive containing the MV2 extension that does not include the Forge software and does not have the extension file in the release section. You can download the extension here.
4. Online Archive, an archive that is automatically updated every day at 00:00 UTC. You can view the automatic updates for the MV2 extension in the releases section.

# Contributions
You can contribute to this archive by submitting a Feature Request (FR) in the issues section. Please include the extension’s name, a link to the extension (if it’s still available in the extension store), and a general description of the proposed extension’s functionality. I’m very open to all kinds of feedback.
